## Participation
Do not automatically force every current MIDEA activity to use the multi-store participant text. Use explicit current inputs first; otherwise use the historical default only when applicable.

## Fulfillment
Route virtual / physical / order-bound reward rules from the actual mechanics.
Do not treat task-value-draw or order-draw as mandatory brand mechanics.

# 六、注意事项：LOCKED BASE

When MIDEA structure applies and the current campaign uses this historical notice base, preserve the following text exactly unless an explicit current-user conflict requires an appended correction annotation.

(1) 活动过程中，凡以不正当手段（如作弊领取、恶意套取、刷信誉、虚假交易、扰乱系统、实施网络攻击等）参与本次活动的用户，商家有权终止其参与活动，并取消其参与资格、停止发放奖品或追回已经发放的奖品，如给商家造成损失的，商家将保留向违规用户继续追索的权利；

(2) 如遇不可抗力（包括但不限于重大灾害事件、活动受政府机关指令需要停止举办或调整的、活动中存在大面积作弊行为、活动遭受严重网络攻击或因系统故障导致活动中奖名单大批量出错，活动不能正常进行的），商家有权取消、修改或暂停本活动；

(3) 是否获得奖品以活动发布者后台统计结果，如公布有误，商家有权进行更正并以更正后中奖清单为准；

(4) 本活动发放的所有奖品不得折现、不得转赠他人、不得为他人付款。

(5) 活动主办方不对参与者网络及活动平台的稳定性及安全性负责，并不对因网络传输原因而导致参与者提交的信息错误或延误承担任何责任。所有参与者完全自愿选择参加本次活动，商家在法律允许范围内可对本活动未尽事宜进行解释说明。

(6) 如对本次活动有任何其他问题，请详询京东在线客服。

## Guard
Project-specific dates, prize inventories, task limits, draw thresholds, store scope, and campaign names are never promoted into brand defaults.
