# Brand Router

## MIDEA
Trigger: brand is 美的 / Midea.

Preferred structure:
1. 活动时间
2. 本活动参与店铺
3. 参与对象
4. 玩法细则
5. 活动玩法发奖规则
6. 注意事项

Default multi-store set may be used only when the user has not supplied the current activity store scope.
Current explicit store scope always wins.

## BYHEALTH / 汤臣倍健
Trigger: brand is 汤臣倍健 / BYHEALTH.

Typical routing dimensions:
- default stores
- participating products: all-store vs specified products
- WeCom friend requirement: either-account vs both-accounts
- order linking
- reward invalidation after cancellation/return/refund
- nutritionist support for order/WeCom exceptions

## Generic
All other brands use the generic JD base unless a brand-specific base has been learned and verified.
