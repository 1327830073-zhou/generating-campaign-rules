# Reward Fulfillment

## VIRTUAL_AUTO_ISSUE
Virtual reward automatically issued to account.

## PHYSICAL_ADDRESS_FULFILLMENT
Winner submits shipping address; merchant/platform ships physical prize.

## PHYSICAL_PRIZE_VIA_COUPON_ORDER
Winner receives a redemption coupon/right, clicks “去使用”, places a symbolic-price order, then merchant ships.

## MANUAL_CLAIM
User must contact customer service / designated staff, register details, or submit proof before payout/fulfillment.

## Numbering rule
If section “奖品领取流程” has only one distinct fulfillment flow, do not add `①`.
If it has 2+ flows, number them `①②③...`.

Count fulfillment-flow types, not SKU count.
