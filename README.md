# 自动生成活动规则 Skill

用于生成、补全、改写和检查京东风格营销活动规则。

这套 Skill 不依赖“整份历史活动模板”，而是先把活动拆成可复用的原子玩法，再根据品牌底座、订单校验、奖品发放方式等重新组合。

当前覆盖的核心玩法包括：

- 答题
- 任务
- 积分 / 活动值
- 抽奖 / 刮刮乐 / 盲盒
- 打卡
- 邀请
- UGC / 内容审核
- 点赞 / 投票 / 外部热度
- 排行榜
- 下单
- 首购 / 复购
- 满额奖励
- 阶梯返利
- 组合购 / 跨品类套购
- 报名锁权
- 奖品锁定与订单生效校验

已沉淀品牌底座：

- 美的 MIDEA
- 汤臣倍健 BYHEALTH

## 使用方式

主入口文件：`SKILL.md`

在支持 Agent Skills 的环境中，将整个仓库作为一个 Skill 目录使用。

如果平台不直接支持 Skill，也可以：

1. 将 `SKILL.md` 作为 Agent/System Instructions；
2. 将 `router/`、`mechanics/`、`gates/`、`rewards/`、`brands/`、`base/` 作为知识文件一起加载。

## 推荐输入

尽量提供：

- 品牌 / 品类
- 活动时间
- 参与店铺
- 参与对象
- 玩法机制
- 指定商品范围
- 奖品
- 金额、次数、时间窗口等关键限制
- 奖品发放方式

关键业务信息缺失时，Skill 会优先标记 `[待确认：...]`，而不是自动编造。

## 设计原则

- 根据行为机制路由，不根据运营名称路由
- 新会员、新客、首购、老客、复购严格区分
- 上传先判断用途，再判断是否属于 UGC
- 参与资格锁定与奖品资格锁定严格区分
- 奖品锁定、奖品生效、奖品发放严格区分
- “确认收货 X 天无售后”作为锁定奖品的生效条件
- 未提供活动值名称时默认使用“积分”
- 固定品牌 / 通用底座不随意改写
